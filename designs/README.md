### How to Run and View the Design System
To open and play with the interactive components:

1. **Python Server (Recommended):**
   Run the following command from the repository root:
   ```bash
   python -m http.server 8000
   ```
   Then open `http://localhost:8000/designs/design-system/` in your browser.

2. **Direct Browser Open:**
   You can also double-click and open the [index.html](file:///c:/Users/ganes/OneDrive/Documents/dl/Desktop/startup/designs/design-system/index.html) file directly in any modern web browser.
